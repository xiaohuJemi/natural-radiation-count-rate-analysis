# 正残差、泊松超额与高计数事件的解释边界

## 1. 正残差

正残差定义为：

```text
r_+(t) = max(X_smooth(t) - B_candidate, 0)
```

其中，`X_smooth(t)` 为平滑计数率，`B_candidate` 为候选局部本底。正残差表示计数率高于候选本底的部分，是最宽泛的相对高计数贡献指标。

解释边界：

- 可以表述为“相对本底正向贡献”或“高于候选本底的计数率偏移”。
- 不应直接表述为“矸石贡献”或“煤矸识别结果”。
- 正残差中可能同时包含真实物料变化、短时扰动和统计涨落。

## 2. 泊松 99% 残差超额

泊松 99% 残差超额定义为：

```text
excess_99(t) = max(X_smooth(t) - PoissonUpper(B_candidate, 99%), 0)
```

它表示计数率超过候选本底泊松统计涨落上限的部分。

解释边界：

- 可以表述为“难以仅由本底随机涨落解释的高计数贡献”。
- 比正残差更严格，因为它排除了本底附近的常规统计波动。
- 仍不能直接等同于真实煤矸标签，因为它缺少人工标注、视频记录或采样化验验证。

## 3. 高计数事件

高计数事件是将连续越过指定阈值、且持续时间不小于 0.3s 的采样段合并得到的离散事件。

解释边界：

- 可以表述为“候选高计数事件”“连续高计数段”或“疑似状态变化事件”。
- 可以分析起止时间、持续时间、峰值、超限面积和相对本底峰值。
- 不应表述为“已经识别出的矸石事件”。

## 4. 三者关系

三者是从宽到严、从连续量到事件量的递进关系：

```text
正残差
  -> 泊松 99% 残差超额
  -> 连续高计数事件
```

正残差回答“相对本底高了多少”；泊松 99% 残差超额回答“是否超出了本底统计涨落解释范围”；高计数事件回答“这种高计数是否在时间上连续并具备事件形态”。

当前论文应坚持上述边界，将研究定位为计数率时间序列信息挖掘，而不是已经完成现场煤矸分类验证。
