# 投稿建议修订版

> 前提：当前暂时没有新增数据、人工标签、传感器参数或现场同步记录。

## 1. 当前版本是否建议投稿

不建议投稿正式期刊。

当前成果适合用作：

- 本科阶段进度汇报。
- 毕业设计或大创后续研究的预实验材料。
- 与老师沟通补充数据和实验信息的技术说明。
- 后续有标签煤矸识别研究的代码和方法准备。

当前不适合用作：

- SCI 论文。
- 高水平中文期刊论文。
- 已验证煤矸识别方法论文。
- 工程可部署智能识别系统说明。

## 2. 原因

当前只有一组无标签自然射线计数率序列。第 3 列已确认只是第 2 列的 30 点移动平均，不是额外数据源。缺少：

- 多组独立放煤过程数据。
- 人工煤矸状态标签。
- 放煤窗口开闭日志。
- 同步视频或采样化验结果。
- 探测器型号、采样周期、测量窗口、安装位置、本底计数率等参数。

因此，当前只能说明计数率序列存在阶段变化，不能证明这些阶段对应煤、夹矸或顶板岩石状态。

## 3. 无新增数据下的可发表性判断

| 目标 | 当前可行性 | 说明 |
|---|---|---|
| SCI 期刊 | 不可行 | 缺少标签、泛化验证和方法创新 |
| SCI 会议 | 基本不可行 | 可作为想法雏形，但实验证据不足 |
| 《煤炭学报》 | 不可行 | 机理深度和实验严谨性不足 |
| 《煤炭科学技术》 | 暂不建议 | 至少需要多组数据或现场验证 |
| 《工矿自动化》 | 暂不建议 | 需要工程验证或动作日志支撑 |
| 本科毕业设计/课程论文 | 可行 | 需诚实定位为探索性分析 |
| 大创/课题中期汇报 | 可行 | 可展示已完成工作与后续需求 |

## 4. 如果后续补到数据后的投稿路线

### 4.1 补到多组无标签数据

可定位为：

> 自然射线计数率阶段变化规律探索。

仍不应报告识别准确率。可考虑普通会议或一般工程技术类期刊。

### 4.2 补到多组有标签数据

可定位为：

> 基于自然射线计数率时序建模的综放工作面煤矸状态识别。

此时可考虑：

- 《工矿自动化》
- 《煤矿安全》
- 《煤炭科学技术》

### 4.3 补到充分现场验证和方法创新

如果有多矿井/多工作面数据、清晰标签、对比实验、误报漏报分析和现场响应延迟分析，再考虑：

- 《煤炭学报》
- `International Journal of Coal Science & Technology`
- `Sensors`
- `Measurement`

## 5. 当前建议

当前最合理的路线不是投稿，而是先把项目整理成一份严谨的本科阶段进度材料，并用它向相关老师沟通补充数据、传感器参数和现场记录。只有补齐 ground truth 后，才值得重新讨论投稿目标。
