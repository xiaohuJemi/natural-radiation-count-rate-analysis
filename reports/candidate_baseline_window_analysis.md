# 候选局部本底窗口挖掘阶段报告

## 1. 目的

根据老师反馈，当前研究不再分析本底差异的形成原因，而是在每段计数率时间序列内部建立局部本底基准。本模块的目的，是在没有刮板机清空信号、支架动作时间和人工标注的条件下，仅利用自然伽玛计数率时间序列，挖掘可作为局部本底参考的候选稳定窗口。

需要强调：本模块识别的是“候选局部本底窗口”，不是严格工程意义上的“刮板机清空真本底窗口”。

## 2. 判据设计

对 `ma10_count_rate` 使用 5s 滑动窗口，计算以下指标：

- 窗口均值；
- 窗口标准差；
- 变异系数 `cv = std / mean`；
- 极差比例 `(max-min)/mean`；
- 线性斜率；
- 相邻点最大变化幅度。

候选窗口需同时满足：

1. 窗口均值处于本序列低计数区间；
2. 变异系数不超过 `0.05`；
3. 极差比例不超过 `0.18`；
4. 斜率绝对值不超过 `1 cps/s`；
5. 相邻点最大变化不超过 `4 cps`。

随后按综合稳定性得分排序，选择最多 3 个互不重叠的窗口作为重点候选本底窗口。

## 5. 阶段性解释

1. 三类工况均能从计数率序列内部识别出低位、稳定、持续的候选局部本底窗口。
2. 候选窗口主要集中在显著高计数段出现之前，符合“先建立局部本底，再判断后续相对升高”的分析逻辑。
3. 当前窗口不能等同于现场真实清空窗口，因为缺少煤流检测、支架动作和人工标注；但它们可以作为有限数据条件下的局部本底参考。
4. 本模块为下一步自适应阈值重构提供了基础：后续阈值可从固定初始 5s 本底，升级为基于候选本底窗口的 `B(t)`。

## 6. 后续衔接

```text
T(t) = B_candidate(t) + ΔC
T_pois(t) = PoissonUpper(B_candidate(t), confidence)
```

并与固定阈值、初始段静态本底阈值进行对比。
