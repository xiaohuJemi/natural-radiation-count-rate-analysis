# CSV 长序列本底与相对辐射贡献分析

## 1. 分析目标

本模块针对 `new_data/2025-11-28.csv` 进行重新分析。根据老师确认，CSV 中的 `阈值电压mv=300` 是设备电压参数，不属于自然射线计数率分析对象，因此本模块只使用：

- 时间；
- 计数率。

分析目标从“按 300 阈值筛查高值”修正为：

```text
y(t) = B(t) + G(t) + e(t)
```

其中：

- `B(t)`：随时间缓慢变化的本底计数率；
- `G(t)`：相对于本底的短时辐射贡献；
- `e(t)`：计数涨落和测量噪声。

由于 CSV 没有煤矸工况标签，`G(t)` 只能称为“相对本底的辐射贡献”，不能直接等同于煤矸影响。

## 2. 当前方法

CSV 原始时间戳存在同一秒内多行数据，因此先按时间戳聚合为秒级序列：

- `count_rate_mean`：同一时间戳下计数率均值；
- `count_rate_median`：同一时间戳下计数率中位数；
- `count_rate_min/max`：同一时间戳下计数率范围；
- `n_samples`：该时间戳下采样数量。

然后进行本底估计：

1. 对秒级均值做 `5s` 居中滑动平均，得到平滑计数率；
2. 在平滑计数率上用 `300s` 居中滚动窗口的 `20%` 分位数估计慢变化本底；
3. 计算相对本底贡献：

```text
G(t) = y_smooth(t) - B(t)
```

4. 将 `G(t)` 的正值部分记为 `positive_component`；
5. 使用 `positive_component` 的 `99%` 分位数标记相对高贡献时段。

注意：这里的 `99%` 分位数只是数据内部的相对高贡献筛查线，不是工程阈值，也不是煤矸判别阈值。

## 3. 三个研究问题的处理情况

### 3.1 本底值影响与煤矸影响拆分

当前已实现初步拆分：

- `background_estimate`：估计本底；
- `radiation_component`：平滑计数率减去估计本底；
- `positive_component`：只保留正向贡献；
- `component_high`：相对高贡献时段标记。

该方法可以分析本底随时间的变化，以及相对本底的短时辐射增强。但由于缺少人工标签、视频记录或放煤动作日志，不能直接证明这些短时增强均来自煤矸流。

### 3.2 前序支架放煤对当前探测点的影响

当前 CSV 只有单个时间序列，缺少以下信息：

- 多支架同步计数率；
- 前序支架放煤口开闭时间；
- 刮板输送机速度；
- 支架间距；
- 煤矸流运输延迟。

因此当前无法定量剥离前序支架影响。论文中应将其作为潜在干扰因素和后续数据需求，不作为当前研究重点。

### 3.3 工作面推进和环境变化对本底值的影响

CSV 是长时间序列，可以观察 `B(t)` 随时间的变化，因此可用于讨论“本底存在时间漂移”。但由于缺少工作面推进距离、设备安装状态、探测器位置变化等记录，不能证明本底变化一定由工作面推进造成。

当前可采用谨慎表述：

> CSV 长序列显示估计本底存在随时间变化的现象，说明固定本底假设在长时间监测中可能不足。该变化可能受工作面环境、设备状态、残留煤矸或推进过程影响，但当前数据无法区分具体来源。

## 5. 当前结论边界

可以说：

1. CSV 长序列可用于研究计数率本底随时间的变化。
2. 相对本底贡献可用于筛查短时辐射增强片段。
3. 固定本底假设在长时间序列中可能不充分。

不能说：

1. CSV 中的相对高贡献片段已经被证明是煤矸混入。
2. 本底变化已经被证明由工作面推进导致。
3. 前序支架放煤影响已经被定量剥离。
